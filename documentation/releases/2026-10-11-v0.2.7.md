# Watai 0.2.7: Full-Card Generation Preview

Status: frontend-only release; deployed and verified (public bytes and signed-out render).
Continuous Production Milestone, not a DoD closure receipt.

## Scope

Follow-up to 0.2.6. The chat image-generation placeholder now renders the noise stipple
across the entire card instead of only the media box, and shows "Generating image" as a
centred frosted overlay (translucent `--color-bg`, `--blur-appbar` backdrop blur with
saturation, hairline border, `--elevation-1`) instead of a caption row. The empty media box
(requested aspect ratio) and reserved action-bar height remain underneath, so the card keeps
the decoded card's exact size and the image still replaces it without reflow. The card is
one accessible image labelled "Generating image"; the visible overlay text is
`aria-hidden` to avoid a duplicate announcement. Create image "Generating…" cards use the
same frosted label treatment. Colours and animation are unchanged from 0.2.6.
