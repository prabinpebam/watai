# Watai 0.2.2 chronology hotfix

Status: chronology-only hotfix deployed; exact package/public assets verified.
Authenticated production chat remains a manual validation requirement.

## Scope

Preserve submitted prompts during stale history reads, keep the once-assigned logical
prompt/reply timestamps through API persistence, correlate realtime snapshots with
the acknowledged assistant ID, and retain completed replies until history takes over.
Completion ownership is fenced so an old run cannot restore a cleared handoff or
remove a replacement run. Ordering comparator, ChatView layout and scroll rules are
unchanged. No historical timestamps or data are rewritten.

The frontend requires the compatible API first. Old clients remain accepted but must
reload to receive the client-side fixes. All unrelated DoD work and the Windows
continuation watchdog remain paused/disabled until user direction.
