# Watai 0.2.4: Integrated Hardening Release

Status: API and frontend deployed; exact public bytes, public render and API health verified.
This is a product milestone under the Continuous Production Milestones process.
It is **not** a DoD closure claim: under the autonomous-delivery Definition of Done
0 of 52 audit findings are closed and the canonical plan remains `BLOCKED_SAFE` at
H01 (no independent signing authority exists).

## Scope

Integrates the local hardening work recorded in
`documentation/implementation/2026-09-10-autonomous-delivery/README.md`
(local candidates for S10, S15, S16, S21, S22, S23, S29, S36, S37, S40 and related
follow-ups) onto the deployed master, preserving the v0.2.2 chronology hotfix,
v0.2.3 image alpha support and the 2026-09-29 run-admission hotfix.

- Memory: revision-safe edits with per-record claims and Retry, request-keyed filters,
  bounded inventory/profile reads, temporal validity labels, active-archive export and
  preview-only import inspection, exclusion-checked manual saves and edits, fenced
  extraction jobs, 500 ms bounded recall and token-counted context (cl100k/o200k).
- Sync/chat: clear-device and account generation fences, preserved prompt/reply
  handoff ownership, bounded archive response reading.
- Realtime: no duplicate reconnects; resume on online/page-show/visible.
- Library/images: cancellable uploads and stale-load rejection, detail Retry, image
  worker execution fencing.
- Voice/onboarding: fenced recorder finalization and probes; preferences preserved.
- Credentials: saved and requested provider URLs must be HTTPS
  `*.openai.azure.com`, `*.cognitiveservices.azure.com` or `*.services.ai.azure.com`
  without ports, credentials, fragments or queries. A count-only production check
  found all 3 saved endpoints compatible before deployment.

Disabled by default and unchanged in production: memory indexing timer
(`MEMORY_INDEX_ENABLED` absent), model-memory containment (`MEMORY_CONTAINED` absent),
queue names (`RUN_QUEUE`/`IMAGE_QUEUE`/`MEMORY_QUEUE` absent, defaults used).
No app setting, Cosmos container/index, consent, deletion or privacy ledger changed.

## Runtime

Production remains Node 20 on Flex Consumption. Source declares Node 24
(`api/package.json` engines/build target, `infra/*.bicep`), but this release bundle
was built with `--target=node20` and keeps the predecessor package's `package.json`
and dependencies. The Node 24 runtime migration remains a separate milestone.
The exact package passed an official Node v20.20.2 (SHA-256 verified) smoke:
bundle load, registration of 46 functions and both tokenizer encodings.
