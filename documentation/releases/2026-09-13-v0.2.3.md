## Scope

Chat's image tool now exposes `background: auto | opaque | transparent` and instructs
the chat model to select transparent for requests for true alpha, a transparent
background, no background, or background removal. Transparent objects alone do not
imply a transparent background. Both generation and editing forward the validated
choice to the image endpoint and request PNG output. No background keyword parser
or extra model call is added. Default chat requests use auto.

The image adapter also supports optional compression, multipart masks, and edit
output format. Studio edits preserve their stored output format; Studio does not
use chat's semantic background selection. No new mask UI is included.

Uses the existing saved Azure resource/key and configured image deployment. The
user identified `gpt-image-2.5-sunburst`; this release does not rewrite credentials
or force another model on other users. Provider alpha output has not been tested.
