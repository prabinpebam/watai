## Scope

Chat's image tool accepts `background: auto | opaque | transparent`, with instructions
to select transparent for transparent backgrounds, true alpha, no background, or
background removal. Generation and edits forward the validated option and request PNG.
Transparent objects alone do not imply transparent backgrounds. Default is auto.

The adapter also accepts optional compression and multipart masks. Studio edits
preserve output format; Studio's direct prompt flow does not use chat's semantic
background selection. No new mask UI or extra model request is introduced.

Uses the saved Azure endpoint/key and configured image model. The user identified
`gpt-image-2.5-sunburst`; credentials and other users' model settings were not changed.
Chat chronology, data, privacy/consent ledgers and app settings are unchanged.
