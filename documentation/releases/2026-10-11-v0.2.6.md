# Watai 0.2.6: Noise Placeholder For Image Generation

Status: frontend-only release; deployed and verified (public bytes and signed-out render).
Continuous Production Milestone, not a DoD closure receipt.

## Scope

While an image generates, chat and Create image now show the stipple animation from
[prabinpebam/noise-animation](https://github.com/prabinpebam/noise-animation)
(commit `3c53fe35583760606284414293e817b8cd6a1d7b`) at its default settings, without
displacement or the mouse-triggered ripple:

- two inverted Perlin layers (scale 0.004/contrast 3 and 0.009/contrast 5) drifting in
  opposite directions at 0.005 per 60 Hz frame (refresh-rate independent);
- Poisson-disk stipple, minimum distance 5 on a 0.9-resolution grid, dot radius 0.1–2 px,
  larger where the inverted noise is darker.

Colours follow the theme with soft greys: light `--gray-400` dots on `--gray-50`, dark
`--gray-400` dots on `--gray-900` (`--color-noise-dot`/`--color-noise-bg`). The canvas is
decorative (`aria-hidden`; the container keeps its "Generating image" label), uses the
device pixel ratio up to 2, pauses off-screen, renders one still frame under reduced
motion and repaints immediately on theme change. Image Studio "Queued" cards and the
download/decode veil are unchanged. The card geometry and chat ordering are unchanged.

Implementation: `src/design/noise/perlin.ts` ports noisejs `perlin2` (Joseph Gentle;
Stefan Gustavson's public-domain algorithm) with its seed-0 tables; `stipple.ts` holds the
demo's model; `NoiseStipple.tsx` renders it. Noise is evaluated only at stipple points,
which is output-identical to sampling the demo's hidden full noise image and about 37x
less work; all dots are batched into one fill.

## Evidence

- `perlin2` matches the original package to 12 decimals at 10 reference points; stipple
  brightness matches 7 golden values produced by the demo's `generateNoiseImage` formula
  with the original library. Poisson spacing, grid mapping and batched drawing tested.
- Full frontend suite: 93 files / 808 tests. Typecheck, design-system and contrast checks
  pass. Chronology browser test: desktop/mobile pass; both negative controls detected.
- Headless capture of the real placeholder (418 px, DPR 2): light top colours
  `#f4f4f5`/`#a8a8b3`, dark `#1f1f24`/`#a8a8b3`; frames differ after 1 s (animating);
  no page errors. Side-by-side with the original demo (ripple/displacement off) shows the
  same stipple density and cloud structure.
- No API, configuration or data change. API remains `hardening-2026-10-11-r1` on Node 24.
